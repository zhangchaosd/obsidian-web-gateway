# Aurora Launch

Aurora 是一个虚构的隐私优先知识工作区。本项目页集中管理从内测到正式发布的全部准备工作。

## 项目目标

1. 让新用户在 3 分钟内理解产品价值
2. 保持本地文件是唯一真实数据源
3. 在桌面与移动浏览器中提供一致体验

## 发布清单

### 产品

- [x] 核心浏览与编辑流程
- [x] 冲突检测与恢复性删除
- [ ] 完成移动端最终验收
- [ ] 验证 5000 篇笔记的索引性能

### 内容

- [x] 快速开始指南
- [ ] 录制 90 秒产品演示
- [ ] 准备发布公告

### 运营

- [ ] 安排发布后 48 小时值守

## 关键指标

| 指标 | 目标 | 当前 |
| --- | ---: | ---: |
| 首次成功打开笔记 | < 30 秒 | 24 秒 |
| 编辑保存成功率 | > 99.9% | 99.97% |
| 移动端任务完成率 | > 90% | 88% |

## 风险与应对

> 最大风险不是缺少功能，而是用户不确定自己的文件是否安全。

因此所有破坏性操作都必须明确说明结果，并提供恢复路径。相关准则见 [[Areas/Design Principles]]。
